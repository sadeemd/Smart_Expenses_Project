# Mini Project - Data Analysis (CSV)

## Overview
This mini project loads a CSV file, cleans the data, calculates key metrics, applies a filter, shows a Top 5 table, and creates one chart.  
It also writes a short summary report into a text file.

## Project Files
- `data.csv` : The dataset (expenses data)
- `notebook.ipynb` : Data cleaning + analysis + filtering + plotting
- `report.txt` : 5-line summary report generated by the notebook
- `figure.png` : Saved chart image (generated by the notebook)

## Steps Done
1. Load the dataset from `data.csv`
2. Clean the data (convert date, fix types, remove missing values)
3. Calculate KPIs:
   - total amount
   - average expense
   - highest expense
   - lowest expense
   - number of rows
4. Filter the data (example: Food category only)
5. Show the Top 5 highest expenses
6. Create one chart: total expenses by category
7. Save results to `report.txt`
