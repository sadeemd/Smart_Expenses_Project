# Pandas CSV Analysis (Day 3)

This mini project reads a CSV file using **Pandas**, explores the dataset, handles missing values in a simple way, and generates clear summary outputs.

---

## Project Goals

- Read a CSV file using `read_csv()`
- Display the first rows using `head()`
- Show dataset structure using `info()`
- Generate statistical summary using `describe()`
- Handle missing values (basic cleaning)
- Print:
  - **Top 5 highest average scores**
  - **Bottom 5 lowest average scores**
- Save cleaned data and summary reports to files
