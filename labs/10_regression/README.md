# Day 10 — Linear Regression 1 (Predict Amount)

## Goal
Train a simple Linear Regression model to predict a numeric value (**amount**) using basic features.

## What You Will Do
1. Create a `LinearRegression` model
2. Fit (train) the model
3. Predict values on test data
4. Calculate **MAE** and **R2**
5. Plot **y_true vs y_pred**

## Features / Target
- **Target (y):** `amount`
- **Features (X):** `day_of_week`, `category_id`
- **Extra Feature (Mini Challenge):** `is_weekend`
